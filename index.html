WHAT YOUR HANDS DO

          
 1 2 3 4 5 6 7 8 9 0   chord bed
 Q W E R T │ Y U I O P   bass  │ bell
 A S D F G │ H J K L ;   drums │ MELODY
 Z X C V B │ N M , . /   low   │ voice

          
    
            
  • hold a key → the note holds that long
    • 
            
  • same key 4× → drum roll / ratchet
    • 
            
  • Shift → deliberately outside note
    • 
            
  • type faster → brighter, denser, an octave layer fades in
    • 
            
  • steady rhythm → tighter, more echo
    • 
            
  • pause then type → accent with a long tail
    • 
            
  • Backspace → reverse tail (and it stays in the loop)
    • 
            
  • Complexity 30+ → repeats climb chromatically, long words climb
    • 
            
  • Complexity 50+ → alternating hands add a 5th
    • 
            
  • Complexity 70+ → every 4th note gets a sub
    • 
          

          
Nothing here is random. Same keys, same timing, same settings → the same performance, note for note. The ambience around it can vary a little between replays.
